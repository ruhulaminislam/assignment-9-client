# SalonBook — Complete Design System

**Version:** 1.0  
**Project:** SalonBook — Salon Appointment Booking Platform  
**Design Direction:** Modern, Clean & Warm Luxury  
**Theme:** Light Theme  
**Status:** Initial Design System

---

## 1. Brand Overview

### 1.1 Brand Identity

SalonBook is a modern salon appointment booking platform that connects customers with salon and beauty services.

The platform allows customers to discover services, explore service details, request appointments, manage bookings, and complete payments.

The design should communicate:

- Elegance
- Trust
- Comfort
- Simplicity
- Professionalism
- Modern Beauty & Wellness

### 1.2 Brand Personality

SalonBook should feel like a premium beauty and wellness platform.

The visual identity must be:

- Modern but not overly decorative.
- Luxury but not excessively flashy.
- Minimal but not visually empty.
- Elegant but easy to use.
- Professional and accessible.

Avoid designs that look overly colorful, childish, crowded, or generic.

---

## 2. Design Philosophy

The entire platform must follow one consistent design language.

The main design principles are:

1. **Consistency:** Public pages, customer dashboards, and admin dashboards must share the same visual identity.
2. **Clarity:** Users should understand the interface without unnecessary visual complexity.
3. **Simplicity:** Avoid unnecessary decorative elements and excessive UI components.
4. **Elegance:** Use typography, spacing, and colors carefully to create a premium appearance.
5. **Usability:** Visual beauty must never compromise usability.
6. **Responsiveness:** Every page and component must work properly on mobile, tablet, and desktop.

## 4. Semantic Colors

Semantic colors are reserved for system feedback, appointment statuses, payment statuses, alerts, and validation messages.

| Type | HEX | Soft Background | Usage |
|---|---|---|---|
| Success | `#287A55` | `#E6F3EA` | Confirmed, Paid, Successful |
| Warning | `#956515` | `#FFF2D8` | Pending, Attention Required |
| Error | `#B94343` | `#FBE9E7` | Cancelled, Failed, Errors |
| Info | `#386A91` | `#E8F1F8` | Informational messages |
| Disabled | `#89847E` | `#EAE6E1` | Disabled and unavailable elements |

### 4.1 Usage Rules

- Success colors indicate completed or successful actions.
- Warning colors indicate pending or attention-required states.
- Error colors indicate failed or cancelled states.
- Info colors communicate neutral information.
- Disabled colors indicate unavailable or inactive controls.

Semantic colors must not replace the primary brand palette.

Use them only when their meaning is relevant.

## 5. Typography System

### 5.1 Font Pairing

The selected font combination is:

- **Heading Font:** Playfair Display
- **Body Font:** Inter

Playfair Display provides an elegant editorial appearance, while Inter maintains readability and usability.

### 5.2 Typography Usage

**Playfair Display**

Use for:

- Hero headings.
- Main page titles.
- Important section headings.
- Large promotional headings.
- Major editorial text.

**Inter**

Use for:

- Navigation.
- Buttons.
- Forms.
- Labels.
- Body paragraphs.
- Service cards.
- Tables.
- Dashboard content.
- Supporting information.

Do not use Playfair Display excessively in dashboard interfaces.

- Use responsive font sizes on smaller screens.
- Keep body text comfortable and readable.

## 6. Logo and Brand Mark

### 6.1 Logo Composition

The selected composition is:

**Symbol on the Left + SalonBook Wordmark on the Right**

The logo must work as a unified horizontal brand identity.

### 6.2 Symbol Direction

Selected direction:

- Abstract geometric symbol.
- Modern and clean appearance.
- Continuous-line geometric reference.
- Smooth curves and balanced geometry.
- Minimal visual complexity.

The selected visual reference is the first Continuous Geometric Line concept from the design review.

Do not replace this direction with generic scissors, flowers, combs, or common beauty icons.

The final logo artwork must preserve the chosen reference direction.

### 6.3 Wordmark

The brand name must appear exactly as:

**SalonBook**

Keep the wordmark clean, readable, and visually balanced with the symbol.

### 6.4 Logo Color

Primary logo treatment:

- Charcoal `#292824`
- Muted Brown `#A58B73` as an optional restrained accent.
- Warm Ivory `#F7F3EE` or White backgrounds.

### 6.5 Logo Variations

The identity should support:

1. Horizontal logo with symbol and wordmark.
2. Symbol-only version for favicon and compact spaces.
3. Light-background version.
4. Dark-background version.

The logo must remain recognizable at smaller sizes.

**Important:** The selected concept is a visual direction, not a completed vector logo. Do not invent a different final logo without approval.

## 7. Button Design

Buttons must follow the Warm Luxury visual identity.

- Minimal.

- Easy to recognize.

## 11. Spacing and Layout

### 11.1 Spacing Philosophy

The platform should feel spacious, balanced, and organized.

Avoid crowded layouts.

Use consistent spacing between:

- Sections.
- Headings.
- Cards.
- Form fields.
- Navigation elements.
- Buttons.
- Content groups.

### 11.2 Border Radius

Recommended visual direction:

| Element | Radius |
|---|---|
| Small Controls | 8px |
| Buttons | 8–12px |
| Inputs | 8–12px |
| Cards | 12px |
| Larger Containers | 12–16px |

These are design recommendations. Keep the radius consistent across similar components.

### 11.3 Shadows

- Prefer subtle and soft shadows.
- Avoid dark or heavy shadows.
- Use shadows only when they help establish visual hierarchy.
- Do not add shadows to every element.

### 11.4 Borders

- Use subtle neutral or Taupe borders.
- Avoid visually heavy outlines.
- Keep borders consistent across cards, forms, and containers.

### 11.5 Layout

- Use clear alignment.
- Maintain consistent content spacing.
- Avoid unnecessary full-width elements.
- Ensure proper content hierarchy.
- Keep layouts responsive.

## 17. Accessibility and Usability

- Maintain readable text contrast.
- Use clear labels for inputs.
- Provide visible focus states.
- Ensure buttons have understandable labels.
- Do not communicate status through color alone.
- Provide readable error and success messages.
- Maintain usable touch targets on mobile.
- Avoid unnecessary animations.
- Respect reduced-motion preferences where animations are implemented.

---

## 18. Motion and Interaction

Interactions should feel smooth and restrained.

Recommended behavior:

- Subtle button hover transitions.
- Smooth navigation interactions.
- Gentle card hover effects where appropriate.
- Clear loading states.
- Appropriate feedback after user actions.

Avoid:

- Excessive animations.
- Large decorative motion.
- Distracting transitions.
- Unnecessary parallax effects.

Interaction should improve usability, not distract users.

---

## 19. Design Implementation Guidelines

When implementing the design system:

1. Follow the selected Warm Luxury theme.
2. Use the defined colors consistently.
3. Use Playfair Display and Inter according to their roles.
4. Maintain the approved logo direction.
5. Keep buttons and cards visually consistent.
6. Follow the approved form and navigation styles.
7. Use semantic colors only for meaningful feedback.
8. Keep the UI responsive.
9. Prefer existing project components and installed libraries.
10. Avoid unnecessary dependencies.
11. Do not introduce a new design direction without approval.
12. Do not make unrelated UI changes while implementing a requested feature.

If a specific design detail is not defined in this document, use the existing design language and choose the simplest consistent solution.

If a decision would significantly change the brand identity or user experience, ask for approval before implementing it.

## 20. Final Design Principles

SalonBook must always maintain the following identity:

**Warm Luxury + Modern Minimalism + Clear User Experience**

The platform should feel:

- Premium, not flashy.
- Modern, not generic.
- Elegant, not complicated.
- Minimal, not empty.
- Consistent, not repetitive.
